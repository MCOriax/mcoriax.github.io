Commands & Permissions

Every /identity command, what it does, and the permission it needs.

Player commands

/identity

Open the main Identity GUI (1-row compact menu).

/identity help

Show the help message with all available commands.

/identity wiki

Send clickable links to the project wiki, one per line, for the GitHub and GitLab copies of this site; clicking a line opens it in your browser.

/identity check

Inspect the identity key in your hand or your currently equipped identity.

/identity unequip

Unequip your current identity.

/identity alias

Show the alias of the identity you are currently wearing, or a hint on how to claim one when it has none. On the base Player identity it reports that the identity always goes by your Minecraft name.

/identity alias <name>

Claim the given name as the alias of the identity you are currently wearing.

  • Alphanumeric only. A name may contain English letters and digits only, and at most 32 of them. Spaces, underscores, hyphens, and symbols are rejected.
  • Unique across the whole server, ignoring case. Two aliases that differ only in capitalisation are the same alias: if someone already holds Alex, then alex and ALEX are refused for everyone else.
  • Your capitalisation is kept. The name is stored exactly as you typed it, so Alex stays Alex wherever it is shown.
  • An alias is permanent. Once an identity carries one it is never renamed — running the command again is refused with "This identity alias is already set as ...". Choose the name you want to keep.
  • The base Player identity has no alias. It is your own character rather than a role you put on, so it always goes by your Minecraft name and the command is refused there. Every other identity can claim one, alternative base identities included.
  • Your alias is the name everyone sees. While that identity is equipped, the alias replaces your Minecraft name in chat and in the tab list, shown after the profession of the identity you are wearing. Unequip it, or wear an identity with no alias, and your Minecraft name comes straight back.
/identity stats

View your remaining unspent stat points. A shortcut that behaves exactly like /identity stats get.

/identity stats get

View your remaining unspent stat points.

/identity stats add <stat_type> <amount>

Spend your stat points to upgrade specific attributes. Available stats are energy, health, food, strength, defense, wisdom, luck, agility, and resilience. For example, typing /identity stats add food 5 spends five points on food. Tab completion suggests every stat.

Admin commands Operators

/identity get <profession|random> [texture]

Admin tool to give a new identity key. Name a profession, or choose random to have one assigned the first time the key is used. You can optionally give it a custom head texture.

/identity base add <player> <amount>

Grant a player additional alternative base identities, assigning each new slot a random non-player profession. For example, /identity base add MCOriax 2 gives the player MCOriax two extra identities, each of a random class.

/identity base add <player> <profession> <amount>

The same grant, but every new slot is assigned the profession you name, for example three Miner identities. The Player profession cannot be added as a sub-identity — it is reserved for the primary identity, so the command is rejected and the sender is notified. The new identities are saved straight away, so they appear in the Player Identity GUI right away.

Permissions

Every command has its own permission node, so a server can switch any single command on or off with a permission plugin. Servers that never touch permissions get the sensible defaults below: players can use every player command, and only operators can use the admin commands.
