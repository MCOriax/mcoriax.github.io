How profession EXP works

Every profession is described by its own file in the plugin's professions folder. Server owners can change how any profession levels by editing its file, or create a new profession by adding one. New professions are registered automatically the next time the server starts.

What a profession file sets

  • A unique name, written in lower case, that identifies the profession.
  • A display name that players see.
  • The maximum level and the EXP needed per level.
  • Starting stats for all nine attributes: energy, health, food, strength, defense, wisdom, luck, agility, and resilience.
  • Bonus points, optionally spread at random across the six primary attributes when an identity is created.
  • Skins, one of which is chosen at random for each new identity.
  • EXP rules: which of the actions below earn experience, and how much.
ℹ️

Editing or deleting a default file does not bring it back automatically; defaults are only written when the file is missing.

EXP gain actions

These are the actions a profession can reward. Open one to see what triggers it, how its reward can vary, and worked examples. A reward is either a fixed amount, such as 10 EXP, or a range, such as 10 to 20 EXP, which awards a fresh random amount between the two every time. The small name beside each title is the name the action goes by in a profession file. All 73 actions are listed.
