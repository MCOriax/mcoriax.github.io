4.6.0 Latest 2026-08-02 · Unequip means unequip

The command that takes an identity off is now called what it does. /identity unuse becomes /identity unequip, matching the wording used everywhere else in the plugin and in this documentation.

⚠️

The old command is gone, not deprecated. /identity unuse no longer runs. A player who types it gets the help listing, which shows the new name — but any macro, command block, or script calling the old form needs updating. So does anything referencing the old permission node, renamed below.

Changed /identity unuse is now /identity unequip

  • The command behaves exactly as before: the same identity-swap cooldown check, the same hand-back of your identity key, and the same return to the base Player profession.
  • Tab completion after /identity suggests unequip, and the /identity help listing shows the new name.
  • See Commands & Permissions for the full reference.

Changed The permission node was renamed with it

  • mcoriax.mcidentity.command.unuse is now mcoriax.mcidentity.command.unequip, so the node matches the command it guards.
  • It is still granted to every player by default, and still inherited by the standard player-commands parent, so a server that never touched it has nothing to do.
  • A server that explicitly granted or revoked the old node must update it. A revocation written against the old name no longer applies, which means the command comes back as allowed until the node is renamed in your permissions plugin.

Note Server owners

  • Drop the new jar in and restart. No schema change, no configuration change, and nothing to migrate on any backend.
  • Behaviour is identical on SpigotMC, PaperMC, and Folia; the permission is declared in each platform's own plugin.yml and all four were updated.
  • Nothing else changed in this release — identities, aliases, professions, stats, and every add-on are untouched.
