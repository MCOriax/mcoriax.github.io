4.7.0 Latest 2026-10-11 · One shared central server connection

The connection MCIdentity uses to talk to the central server is now part of its published developer library, so the add-ons can share it instead of each carrying a copy. Nothing changes in game.

Added A shared central server connection

  • The developer library now includes the central server connection itself: authentication, reading, writing, and the health check that wakes a sleeping server.
  • The add-ons use it when they store their data on the central server, which is why that setup needs MCIdentity 4.7.0 or newer.

Changed A new name in the log

  • Problems talking to the central server are now logged under the connection's own name. A server that filters its log by the old name needs to update that filter.

Note Releases

  • This is the first release published to GitHub Packages and tagged automatically the moment it reached the main branch, so the library on GitHub Packages always matches the plugin.
  • Nothing to do on upgrade: drop the new jar in and restart.
