Change Log — 4.3.0

Permalink for version 4.3.0.

4.3.0 Latest 2026-08-02 · Aliases in chat and the tab list

An alias stops being something you look up and becomes the name everyone sees. Claim one with /identity alias <name> and, for as long as that identity is equipped, it stands in for your Minecraft name in the game chat and in the server tab list.

ℹ️

Nothing to turn on and nothing to migrate. There is no schema change and no new configuration key in this release. Aliases claimed before upgrading start naming their owners as soon as the new jar is running.

Added Aliases in chat

  • A player wearing an identity that has claimed an alias is named by that alias when they speak, in place of their Minecraft name.
  • Only the name is substituted. A prefix another plugin puts in front of the chat line is left where it is, so rank tags and channel markers keep working alongside this.
  • Your capitalisation is kept exactly as you claimed it, so Alex appears as Alex.

Added Aliases in the tab list

  • The tab list shows the same alias, alongside the profession of the identity currently worn.
  • It is written when a player joins, and rewritten the moment an identity is equipped or unequipped — swapping identity renames you straight away rather than after a delay.

Note When your own name is shown

  • A player with no identity equipped keeps their Minecraft name.
  • So does a player whose equipped identity has never claimed an alias — including the base player profession, unless you have claimed one for it.
  • Releasing an alias, or swapping to an identity without one, restores the Minecraft name immediately.
  • See Commands & Permissions for how to claim an alias, and Data Storage for the alias column it is kept in.

Note Server owners

  • Naming a player costs no extra database work: the alias is read from the session already held in memory, so chat and the tab list never wait on storage. This holds on every backend, the central server included.
  • The behaviour is identical on SpigotMC, PaperMC, and Folia.
  • Aliases remain a naming feature only — professions, stats, sessions, and every add-on are untouched by this release.
