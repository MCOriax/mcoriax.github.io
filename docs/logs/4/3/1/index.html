4.3.1 2026-08-02 · Profession prefix in chat

A fix for 4.3.0: claiming an alias no longer costs you your profession prefix in chat.

Fixed The profession is shown in chat again

  • In 4.3.0, a player who had claimed an alias spoke as <Rockbiter> instead of <[Miner] Rockbiter>. The alias replaced the whole name tag rather than only the name inside it, so the profession went missing from every line they sent.
  • Chat now shows the profession and the alias together, exactly as the tab list already did.
  • Players without an alias were never affected, which is why this only appeared once someone claimed one.

Fixed Profession names containing a percent sign

  • A profession whose display_name in professions/*.yml contains a % no longer risks breaking the chat line it appears in.

Note Upgrading

  • Drop the new jar in and restart. No schema change, no configuration change, and nothing to migrate.
  • A prefix another plugin adds to the chat format is still preserved, as before.
