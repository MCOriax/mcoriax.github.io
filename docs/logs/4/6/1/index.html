Permalink for version 4.6.1.

4.6.1 2026-08-27 · Quality and security clean-up

A maintenance release that clears the backlog of code-quality and security findings. Players and server owners will notice no difference.

Security Stats are handled more strictly

  • The plugin now prepares every stat lookup and stat change in advance from the fixed list of nine stats, so a stat name can never become part of a database request. An unknown stat name is simply refused.

Fixed Cleaner shutdown and error reporting

  • Saving the last passive EXP while the server shuts down no longer loses the signal that the server is stopping.
  • Unexpected errors are now written to the server log with their full details, instead of bypassing the log configuration.

Note Server owners

  • No behaviour, configuration, or storage change on any backend.
  • Nothing to do on upgrade: drop the new jar in and restart.
