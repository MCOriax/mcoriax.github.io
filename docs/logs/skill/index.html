0.0.0 Latest 2026-07-28 · Initial release

The first release of MCIdentitySkill, the standalone skill add-on for MCIdentity. Skill items store their data on the item itself, are restricted to a single profession, and are cast through MythicMobs.

Added Skill items stored on the item (PDC)

  • Every skill item carries its data in the Minecraft ItemStack Persistent Data Container. There is no database, no schema, and no migration — the item is the record.
  • Keys, all namespaced to this plugin: skill_code and profession (both required), plus optional display_name, skill_skin, and cooldown_seconds.
  • Item data is treated as untrusted input: values are trimmed, length-capped, and range-clamped, and an item missing a required key is denied rather than partially honoured.

Added Profession restriction

  • A player may equip or use a skill item only while their active MCIdentity profession matches the item's profession.
  • Matching is case-insensitive and ignores whitespace, but is otherwise exact — no wildcard, no prefix match, no alternates.
  • Enforced on inventory click, drag, hotbar selection, and right-click use. Every denial names the profession the item requires.
  • The check fails closed: a malformed item, no active identity, or an unreachable core plugin all deny. There is no setting that turns it off.
  • Skill items are built on player heads and can never be placed as a block — they are equipment, not building material.

Added MythicMobs casting

  • A skill item's skill_code is a MythicMobs skill ID. Using an allowed item asks MythicMobs to cast it with the player as caster.
  • The profession check runs first, so MythicMobs is never consulted for a player in the wrong profession.
  • An unknown skill ID logs a warning and tells the player, never throwing onto the game thread. /skill give warns at creation time when MythicMobs cannot resolve the ID.

Added Commands and developer API

  • /skill info shows what the held item stores and whether you can use it. /skill give <player> <skill> <profession> [cooldown] and /skill clear require mcidentityskill.admin.
  • Cancellable MCIdentitySkillEquipEvent and MCIdentitySkillUseEvent, both fired after the profession check has already passed.
  • Published library modules: mcidentity-skill-api, mcidentity-skill-common, and mcidentity-skill-bukkit.

Note Requirements

  • One universal jar for SpigotMC, PaperMC, and Folia; the server type is detected at enable time.
  • MCIdentity 3.0.0 and MythicMobs are hard dependencies. Without either, the plugin logs a severe message and refuses to enable rather than leaving skills unrestricted or inert.
  • No database is required. The whole configuration file is a single enable switch, which defaults to false.
