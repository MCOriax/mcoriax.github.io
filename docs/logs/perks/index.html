0.1.0 Latest 2026-08-29 · Project set up

The first release of MCIdentityPerks sets the project up: its build, its documentation, and its licence. The plugin itself is not written yet, so this jar contains no gameplay.

Added The foundations

  • A build that produces one universal jar for SpigotMC, PaperMC, and Folia, in the same shape as the core plugin.
  • Documentation describing the three progression systems, Sigils, Relics, and Perks, and the rule that all of their data belongs to the identity rather than the player.
  • The planned storage layout for the six kinds of data the add-on will own.
  • A commercial licence.

Note Not playable yet

  • There are no commands, menus, or storage yet, so there is nothing to install. Follow the Perks page for progress.
