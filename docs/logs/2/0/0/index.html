Change Log — 2.0.0

Permalink for version 2.0.0.

2.0.0 Archived 2026-07-18 · API namespace

A tidier home for the developer API. Every part of the library now sits under the plugin's own name.

Changed Developer API namespace

  • Every public part of the developer library, including the provider and the events, moved under a location named after MCIdentity itself.
  • Plugins built on MCIdentity need to point at the new locations and move to version 2.0.0 of the library. The publisher name is unchanged, so nothing else has to change.

Note Server owners

  • Nothing changes for you — this is a drop-in update. Replace the jar and your commands, permissions, and data all keep working exactly as before.
