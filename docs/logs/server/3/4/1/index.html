Change Log — MCIdentity Central Server 3.4.1

Permalink for MCIdentity Central Server version 3.4.1.

3.4.1 2026-08-28 · Two security hardenings

Two findings from automated security analysis are closed. Neither could be reached through the running API, and both are now fixed where the risk lives.

Security Hardening

  • Stat names are checked at the storage layer as well as when a request arrives, so only the nine known stats can ever reach the database.
  • The container image installs its dependencies without running any of their install scripts.

Fixed Stat changes

  • Adding to a stat now reports its outcome consistently on every path.

Note Operators

  • No change to the API, the storage, or the settings. Both databases behave identically.
