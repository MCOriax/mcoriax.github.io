Change Log — MCIdentity Central Server 3.4.3

Permalink for MCIdentity Central Server version 3.4.3.

3.4.3 2026-08-28 · Fixed stat statements

Reading or changing a single stat now uses statements prepared in advance for each of the nine stats, instead of building one when the request arrives. The same nine stats are accepted and everything else is still refused.

Security Stat statements

  • No part of a request can become part of a database statement for stats any more, on either database.

Note Operators

  • No change to the API, the storage, or the settings.
