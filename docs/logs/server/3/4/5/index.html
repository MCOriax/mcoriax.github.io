Change Log — MCIdentity Central Server 3.4.5

Permalink for MCIdentity Central Server version 3.4.5.

3.4.5 Latest 2026-10-11 · Checked against every plugin

The central server is now checked automatically against the requests every MCIdentity plugin actually sends: the core plugin and the rune, skill, and cosmetic add-ons.

Added Compatibility checks

  • An automated test replays each plugin's requests and confirms every answer contains what that plugin reads.
  • A compatibility table showing which plugin versions each server release supports.

Fixed Documentation

  • The audit log field is now documented under the name the server and plugins actually use.

Note Operators

  • No change to the API, the storage, or the settings. Nothing to do on upgrade.
