What MCIdentity does

Every player has exactly one primary identity — their permanent base Player profession, keyed by their own UUID. Beyond it, players can unlock multiple alternative base identities, each of any other profession, plus equip profession identity keys found in-game. Each identity keeps its own isolated inventory, ender chest, level, and stats, and switching is a full context switch — as if logging into a completely different account.

The whole system is built for performance and safety: identity data can live in SQLite (the zero-configuration default), MySQL, PostgreSQL, or MongoDB, or be owned by the MCIdentity Central Server and reached over the network in the background. Every backend is combined with RAM caching and fully asynchronous access for a lag-free experience on high-population servers.

The MCOriax projects

MCIdentity is a family of projects. The core plugin is the only one a server must install; everything else builds on it.

ProjectWhat it is
MCIdentityThe core plugin. It owns identities, professions, stats, sessions, and storage, and gives other plugins a supported way to build on them.
MCIdentitySkillAn add-on for skill items that only certain professions can use. Each skill lives on the item itself and is cast through MythicMobs.
MCIdentityRuneAn add-on that gives every identity ten rune slots, with its own menu and storage.
MCIdentityCosmeticAn add-on that lets every identity wear its own skin and aura.
MCIdentityPerksAn add-on in development for deeper progression: Sigils, Relics, and Perks.
MCIdentity Central ServerA standalone web service that owns all identity data for a whole network, so game servers never need a database of their own.

Every add-on stores its data against the identity rather than the player, so switching identity switches everything that belongs to it.
