# Website content refresh plan (mcoriax.github.io)

Goal: the site at https://mcoriax.github.io/ describes every MCOriax project accurately,
in prose, with no code or code snippets anywhere.

Done means: no page under `docs/` contains a code block or inline code element, no
build, config, Java or YAML snippet appears in any form, and every page matches what
the repositories say today.

## What "no code" means here

- No `<pre>` or `<code>` element on any page, and no snippet rewritten as plain text.
- Configuration and EXP rules become plain tables and sentences (for example, "breaking
  a diamond ore gives 20 EXP"), not YAML.
- Command names, permission names and file names may still appear as ordinary words in
  tables, since server owners need them, but never as code formatting.
- The developer pages explain what a plugin author can do and where to get the library,
  without showing how to write it.

## Decisions (all approved by owen)

1. **Change-log versions.** Adding log pages for already released versions counts as a
   version claim under the site's rules. Default: add them, since every one is already
   released in its repo.
2. **Rewriting released log pages.** The site's rules say released logs are never
   rewritten. Default: remove only the code formatting and reword class names into
   plain language, without changing what each release says.
3. **Branch names.** The site's convention forbids the session's `claude/` branch, so I
   will use the `docs/...` names above.
4. **The site's own rule.** `.agents/rules/repository.md` still allows consumer code
   blocks. Proposed change (needs your yes, per the discovery protocol): replace that
   allowance with "No page may contain code or code snippets of any kind; describe
   behaviour in prose and tables." If approved it rides on task 7.
5. **Site version.** The site itself is at 1.0.0 (`wiki/logs/1/0/0`). Default: 1.1.0, a minor bump, because pages are added and rewritten but nothing a visitor relies on is removed. Task 8 branches from task 7 and merges last.
